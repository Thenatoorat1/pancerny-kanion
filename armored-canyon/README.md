# Armored Canyon – wersja testowa (v1.2)

Wersja kosmiczna gry (kampania „Inwazja z Księżyca”, UFO, mapa Księżyc), przygotowana pod CrazyGames.
Ten folder to kopia do testów na GitHub Pages: **bez SDK CrazyGames i bez reklam**, z trybem offline.

- Adres: `https://thenatoorat1.github.io/pancerny-kanion/armored-canyon/`
- iPhone: otwórz adres w Safari → Udostępnij → Do ekranu początkowego.
- Postęp kampanii zapisuje się lokalnie w przeglądarce.
- Główna gra „Pancerny Kanion” w katalogu głównym repozytorium jest bez zmian.

Paczka na portal (z SDK CrazyGames, okładki i filmy) powstanie osobno, po dopracowaniu gry.
